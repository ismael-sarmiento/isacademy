# IsAcademy · Project context

Última actualización: 2026-10-12

## Objetivo

Web profesional de academia para **captar alumnos**: cada sección termina en un camino claro al contacto.
El componente lúdico queda acotado a la intro/apertura y a la sección **Recursos** (mundo 3D futuro y curiosidades).
