# IsAcademy · Project context

Última actualización: 2026-10-11

## Objetivo

Web profesional de academia para **captar alumnos**: cada sección termina en un camino claro al contacto.
El componente lúdico queda acotado a la intro/apertura y a la sección **Recursos** (mundo 3D futuro y curiosidades).

## Decisiones vigentes

| Tema | Decisión |
|---|---|
| Marca | **IsAcademy** · "by Ismael Sarmiento" (pequeño, alineado a la derecha) |
| Voz | Plural ("nosotros"), con Ismael como fundador y tutor |
| Logo | SVG. "Is" en **Allura** (dorado `#C8953F`), "Academy" en Space Grotesk (azul marino `#1C2547`). Sin barra de cursor en el logo final |
| Gancho | *La Inteligencia Artificial (IA) te da respuestas. Aquí te enseñamos a pensar.* (se retira "Tutor humano en un mundo artificial") |
| Intro | Se reproduce **en cada visita** (salvo enlaces directos). El "Is" se esboza, "Academy" se decodifica, botones ES/EN y claro/oscuro, solo "Entrar a la academia" |
| Apertura | Mano humana dorada (línea) se lleva "Is" a la izquierda; mano robótica se lleva "Academy" a la derecha. Móvil: solo separación |
| Landing | Hero (mini-clases animadas: Python, Big Data, qué modelo de IA, IA gratis, SQL) · Aulas abiertas · Quiénes somos · Metodología · Materias · Por qué elegirnos · Opiniones · Recursos (curiosidades + consola Python) · FAQ · Reserva |
| Menú | Quiénes somos · Metodología · Materias · Por qué elegirnos · Opiniones · Recursos · [Reservar clase] · idioma y tema a la derecha. Sin "Contacto" |
| Confianza | "Valoración de 5 ★" (sin número de reseñas), "+10 años en el sector tecnológico", "+10 años formando a profesionales". Sin "adolescentes/adultos" |
| Materias | Programación (Python, POO) · Datos e IA (SQL, Analítica, Big Data, Data Engineering, IA) · Acompañamiento (TFG/TFM, Orientación profesional) |
| TFG/TFM | Se guía; el trabajo es del alumno (nunca "te lo hacemos") |
| Contacto | Sin número aún: el canal activo principal es el perfil de tusclasesparticulares. WhatsApp/teléfono "muy pronto" (`js/config.js`). Sin precios |
| Gancho comercial | **Aulas abiertas**: sesiones online y gratuitas cada 15 días para resolver dudas (sustituye a "primera clase gratis") |
| Recursos | Mundo IsAcademy 3D (fase aparte, "Próximamente") + widget de curiosidades de datos e IA |
| Aldea anime 2D | **Retirada** (2026-10-10) |
| Idiomas / temas | ES + EN · claro + oscuro |
| Hosting | GitHub Pages: `ismael-sarmiento.github.io/isacademy` (repo `isacademy`) |
